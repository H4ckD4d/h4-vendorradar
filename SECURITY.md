# Security / Segurança / Seguridad

Report vulnerabilities **privately** via GitHub Security Advisories, not public issues. Never include production secrets, private data, access tokens or unauthorized scan results.

This repository is a bounded prototype. Do not expose the demo with real customer data. API keys are for local demonstration; production requires OIDC/SSO, key rotation, RBAC, gateway rate limits, durable event processing and formal security review.

We support lawful and ethical security work, defensive research and the protection of lives. **We do not claim affiliation with any special-forces or governmental organization.**
