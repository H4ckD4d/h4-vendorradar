# Contributing / Contribuir / Contribuir

We welcome tests, documentation, i18n, API design improvements, accessibility, performance, and authorized defensive security research.

1. Open an issue to discuss large changes.
2. Submit small pull requests with automated tests.
3. Do not include real client data, sensitive credentials, exploit chains or unauthorized activity.
4. Report vulnerabilities privately according to SECURITY.md.
